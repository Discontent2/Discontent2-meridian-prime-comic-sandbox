# Editorial Rule

This board evaluates every image in the 71-image *Visual Journey* collection against the existing 40-spread coffee-table-book plan.

Each image receives exactly one editorial status:

- **LOCK** — preferred hero image for a specific planned spread.
- **ALT** — viable alternate for a specific spread, but weaker than the lock, canon-sensitive, or dependent on crop / retouch / reframing.
- **INSERT** — worth keeping as a secondary image, detail, chapter punctuation, evidence fragment, portrait, or supporting frame; not the primary hero for a spread.
- **CUT** — remove from the main book. This does not mean the image is bad. It means it is redundant, visually off-plan, canon-drifting, or belongs to a different Meridian Prime artifact.

The final book should **not** use 40 full-bleed heroes mechanically.

The current 71-image pool naturally suggests:

- 33 hero-capable LOCK images
- 7 alternate hero candidates
- 18 supporting INSERT images
- 13 images removed from the main book

- Aeonolacertian civilian sequence around Spread 25
- wildlife / natural-history sequence around Spread 31
- Hydropolis infrastructure around Spread 18
- W.A.S. evidence fragments around Spread 37
- Craton travel / infrastructure around Spread 24

This gives the book the rhythm of a photographic monograph rather than a slideshow.

# Final Editorial Position

The strongest version of *Meridian Prime: The Road Remembers* is **not** the version with the most spectacular images.

It is the version where spectacle has consequence.

Cold machinery establishes trust.  
Cities establish inhabitants.  
Quiet interiors establish lived experience.  
Ecology changes the route.  
The archive breaks the book’s certainty.  
The red relay remains unexplained.  
The Lodestar is still there at the end.

The five hero gaps should be filled deliberately rather than with near-matches.
