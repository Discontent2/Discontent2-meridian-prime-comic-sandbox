# Creature Silhouette Plate Rough Layout
## Apocryphal Plate I: Observed, Not Owned

**Project:** Field Guide to Apocryphal Meridian Prime Fauna and Flora  
**Ashcan Title:** Observed, Not Owned  
**Status:** Sandbox Production Layout / Rough Plate Guide  
**Canon Status:** Sandbox only unless promoted through explicit canon review  
**Primary Use:** Page 02 false field plate / reference layout / creature silhouette guide  

---

## Page Purpose

This plate should feel like an old field-guide page that has been revised, censored, damaged, and argued with over time.

It is not a monster menu.

It is a warning document wearing the costume of a scientific plate.

The reader should understand three things instantly:

```text
There are nine major apocryphal lifeforms.
Thor thinks he can organize them.
The page itself suggests organization may be dangerous.
```

---

## Overall Page Layout

Use a damaged **3 x 3 field-plate grid**, but make it imperfect.

```text
┌──────────────┬──────────────┬──────────────┐
│ 1 Index      │ 2 Buckle     │ 3 Girasol    │
│ Orchid       │ Burdenback   │              │
├──────────────┼──────────────┼──────────────┤
│ 4 Crimson    │ 5 Gift-Pod   │ 6 Nightwake  │
│ Glass        │              │              │
├──────────────┼──────────────┼──────────────┤
│ 7 Lung       │ 8 Dwarf      │ 9 Snow-Dire  │
│ Lichen       │ Sauropod     │ Leafcat      │
└──────────────┴──────────────┴──────────────┘
```

Do not make the grid clean. The lines should look hand-ruled, warped by moisture, interrupted by black ink blooms, tape shadows, and redacted coordinate blocks.

---

## Best Visual Hierarchy

The page should read in this order:

1. **Girasol antler silhouette**, top right, mysterious and partly obscured.
2. **Buckle**, top center, unexpectedly solid and charming among stranger shapes.
3. **Index Orchid**, top left, as the key that unlocks the whole plate.
4. The rest of the organisms as threatening little mysteries.
5. Final stamp at bottom:

```text
OBSERVED. NOT OWNED. LOCATION WITHHELD.
```

---

## Spot Color Plan

Primary spot color:

```text
D Girasol Gold
```

Use only in tiny amounts:

```text
Index Orchid pollen dust
Girasol antler glints
one hidden manuscript line running through the grid
one stamp edge or plate number
```

Optional secondary spot colors by variant:

```text
A Acid Magenta: manuscript reaction / strange signal variant
B Rust Red: warning stamp / field censor marks
C Lichen Green: Lung Lichen variant
```

For the main ashcan interior, keep it mostly black and white with **Girasol Gold only**.

# 3 x 3 Cell Layout

## Cell 1: Index Orchid

**Symbolic function:** MacGuffin  
**Placement:** Top left  
**Silhouette type:** delicate botanical key  

Visual:

```text
A black-glass orchid drawn in strict botanical profile.
Thin stem.
Angular petals like wet obsidian shards.
Root threads descend into a small black mineral vein.
```

It should be elegant but not pretty. More living cipher than flower.

Label:

```text
I. INDEX ORCHID
black-glass bloom / pollen-reactive
LOCATION: REDACTED
```

Field note fragment:

```text
Does not reveal. It indexes.
```

Spot color:

```text
Tiny Girasol Gold pollen grains around the flower throat.
```

Damage note:

A redacted block should obscure the lower root system.

---

## Cell 2: Pygmy Pale Burdenback / Buckle

**Symbolic function:** White Elephant  
**Placement:** Top center  
**Silhouette type:** compact animal study  

Visual:

```text
Small pale barrel-bodied animal in side view.
Pygmy hippo mass.
Tapir-like snout.
Rhino-calf stance.
Tiny rounded ears.
Underdeveloped burden ridge.
Short sturdy legs.
```

He should look physically grounded, almost too ordinary for the plate, which makes him funnier and more emotionally important.

Label:

```text
II. PYGMY PALE BURDENBACK
juvenile pack stock? disputed
INDIVIDUAL: BUCKLE
```

Field note fragment:

```text
Projected pack utility: none.
Actual use: friend.
```

Spot color:

None, unless a tiny warm gold edge from the final page stamp touches his label.

Damage note:

Buckle's cell may have chew marks in the corner, as if he got to the plate.

Tiny production gag:

```text
GROWTH EXPECTED / NO RETURNS
```

partially pasted over the lower margin.

---

## Cell 3: Girasol

**Symbolic function:** White Whale  
**Placement:** Top right  
**Silhouette type:** absent giant  

Do **not** show the whole animal.

Use:

```text
partial okapi-like neck silhouette
one elegant leg fragment
crystalline antlers mostly lost into black foliage
internal glow suggested by negative space
```

The Girasol should feel like something the page failed to hold.

Label:

```text
III. GIRASOL
light-following sky-island ungulate
FULL FORM UNCONFIRMED
```

Field note fragment:

```text
Not found. Witnessed around absence.
```

Spot color:

```text
Three or four tiny Girasol Gold glints along the antler branches.
```

Damage note:

This cell should be the most damaged. Torn corner. Ink wash. Coordinates completely blacked out.

---

## Cell 4: Crimson Glass Salamander

**Symbolic function:** Red Herring  
**Placement:** Middle left  
**Silhouette type:** seductive wrong answer  

Visual:

```text
Low amphibian / nudibranch-like body.
Frilled external gills.
Transparent-looking glassy outline suggested with white cuts in black ink.
Tail curled like a question mark.
```

It should look enticing enough to fool Thor and the reader.

Label:

```text
IV. CRIMSON GLASS SALAMANDER
cave margin specimen
MISLEADING INDEX MATCH
```

Field note fragment:

```text
Beautiful. Probably not the answer.
```

Spot color:

For main interior, no red.

For variant, use **Rust Red** along the gill fringe.

Damage note:

Stamp across the cell:

```text
FALSE MATCH?
```

---

## Cell 5: Gift-Pod

**Symbolic function:** Trojan Horse  
**Placement:** Center  
**Silhouette type:** central threat disguised as gift  

This should be the center because it is the most narratively dangerous.

Visual:

```text
Floating seed pod.
Oval body.
Hairline seams.
Trailing root-worm filaments beneath.
Looks like a seed, egg, buoy, and wrapped present all at once.
```

It should look harmless until the viewer notices the roots.

Label:

```text
V. GIFT-POD
floating seed vessel
DO NOT ACCEPT AS GIFT
```

Field note fragment:

```text
The dangerous part is not the shell.
```

Spot color:

No Girasol Gold unless a single misleading speck appears on the seam.

Damage note:

Cell border should be cracked or invaded by root-lines that creep into neighboring cells.

---

## Cell 6: Nightwake

**Symbolic function:** Black Swan  
**Placement:** Middle right  
**Silhouette type:** impossible lifecycle  

Visual:

```text
Moth-bird / glider silhouette.
Wings partly insect, partly avian.
Long trailing tail vanes.
Head too small.
Body too quiet.
```

It should look like a creature caught between categories.

Label:

```text
VI. NIGHTWAKE
moth-bird glider / lifecycle disputed
SEEN AFTER STILL WATER
```

Field note fragment:

```text
Arrives where it should not be able to begin.
```

Spot color:

None on main plate.

Damage note:

Use ghosted duplicate wing positions, like bad registration or uncertain observation.

---

## Cell 7: Lung Lichen

**Symbolic function:** Canary in the Coal Mine  
**Placement:** Bottom left  
**Silhouette type:** survival organism  

Visual:

```text
Patch of lichen growing around a cracked stone or culvert wall.
Branching respiratory pattern.
Looks like coral, lungs, frost, and warning mold.
```

The silhouette should read clearly even without green.

Label:

```text
VII. LUNG LICHEN
oxygen warning / oxygen producer
GLOWS WHEN AIR FAILS
```

Field note fragment:

```text
Breathable until it blooms.
```

Spot color:

For main page, no green unless using the C variant.

For Lichen Green variant, this is the only cell allowed to glow.

Damage note:

Air-meter icon or tiny warning gauge drawn beside it.

---

## Cell 8: Dwarf Craton Sauropod

**Symbolic function:** Sacred Cow  
**Placement:** Bottom center  
**Silhouette type:** ancient protected bulk  

Visual:

```text
Small sauropod-like dinosaur.
Bajadasaurus-inspired neck spines.
Deep swamp posture.
Heavy body partly hidden by reeds.
Not cute, not monstrous.
Old, solemn, difficult to classify.
```

This should feel sacred because it is not trying to impress the reader.

Label:

```text
VIII. DWARF CRATON SAUROPOD
deep swamp relic
DO NOT APPROACH / DO NOT CLAIM
```

Field note fragment:

```text
Some living things survive by refusing relevance.
```

Spot color:

None.

Damage note:

Large stamp:

```text
CULTURAL RESTRICTION
```

Do not over-explain by whom.

---

## Cell 9: Snow-Dire Leafcat

**Symbolic function:** Paper Tiger  
**Placement:** Bottom right  
**Silhouette type:** predator shape, herbivore truth  

Visual:

```text
Snow leopard / dire wolf silhouette.
Large shoulders.
Long tail.
Sharp ears.
Heavy paws.
But mouth full of leaves or bamboo-like stems.
```

At first glance it should seem dangerous. At second glance it should be eating vegetation with total seriousness.

Label:

```text
IX. SNOW-DIRE LEAFCAT
predatory silhouette / herbivorous diet
MISFEAR COMMON
```

Field note fragment:

```text
The teeth were real. The threat was not.
```

Spot color:

None.

Damage note:

A crossed-out old warning:

```text
MANEATER
```

replaced by:

```text
leaf specialist?
```

# Bottom Margin

Use a wide bottom strip like a damaged catalog record.

Elements:

```text
APOCRYPHAL PLATE I
FIELD GUIDE TO APOCRYPHAL MERIDIAN PRIME FAUNA AND FLORA
OBSERVED, NOT OWNED
LOCATION WITHHELD
```

Add redacted coordinate boxes:

```text
LAT: ███████
LONG: ███████
ROUTE: ███████
WITNESS: T.F.
```

Small Buckle hoof print or snout smear can overlap the margin.

## Final Stamp

The final stamp should be big enough to read but not so clean it feels like a logo:

```text
OBSERVED.
NOT OWNED.
LOCATION WITHHELD.
```

Maybe slightly crooked, with uneven ink pressure.

# Layout Notes for Artist

## What Must Read Clearly

```text
Nine organisms
Field-guide structure
Censored locations
Girasol is not fully revealed
Buckle is visually distinct from all the weird organisms
Gift-Pod is central and suspicious
The plate has been handled, revised, and morally corrected
```

## What Should Feel Strange

```text
The grid is too orderly for what it contains.
The labels try to control the organisms.
The damage seems to know more than the notes.
The Girasol cell feels like an absence with antlers.
```

## Avoid

```text
clean encyclopedia page
full-color bestiary
monster trading-card layout
equal dramatic weight for every creature
cute-only Buckle
fully revealed Girasol
fantasy flower glow
generic dinosaur/lizard silhouettes
overexplained science labels
```
