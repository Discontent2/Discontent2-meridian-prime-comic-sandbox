# Field Guide to Apocryphal Meridian Prime Fauna and Flora
## Candidate Canon Parking Lot

**Status:** Sandbox tracking file  
**Canon Status:** Not main canon unless separately reviewed and promoted  
**Purpose:** Track useful inventions from the ashcan concept that might later improve the wider Meridian Prime universe.

---

## Promotion Rule

No idea in this file is main canon by default.

Promotion path:

1. The ashcan concept creates something useful.
2. The idea is tracked here as Candidate Canon.
3. It is reviewed in the main Meridian Prime canon process.
4. Only after explicit approval may it be added to `Discontent2/meridian-prime`.
