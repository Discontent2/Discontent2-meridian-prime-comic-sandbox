# Global Thumbnail Language

## Reading Rhythm

Issue #1 should feel like a procedural system becoming haunted one layer at a time.

```text
Pages 1-6: cab screens, flags, monitors, shame, quiet correction
Pages 7-10: Jasper shock, train danger, command response
Pages 11-16: controlled stop, inspection, GPR logic, crevasse reveal, least-bad decision
Pages 17-22: long crawl, relay/fuel cache, mast knocks, Jack, W.A.S. file
```

## Visual Priority Scale

```text
1. Route disagreement
2. Crew discipline
3. Machinery weight
4. W.A.S. bleedthrough
5. Cryptid and machine-body mystery
```

The page art should never make the crew look careless for wandering. The danger comes from procedure being fed bad ground truth.

## Panel Shape Key

```text
WIDE = horizontal atmosphere / machine scale / route geometry
TALL = vertical mast, tower, crevasse depth, body reveal
TIGHT = hands, screens, radio switches, reflections
GRID = procedure, checklists, crew stations
SPLASH = commercial reveal / issue cliffhanger
```
