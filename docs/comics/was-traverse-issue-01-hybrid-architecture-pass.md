## Purpose

This document adds a hybrid A/B layer to the existing Issue #1 beat sheet without replacing the page-by-page breakdown.

It is a production-facing architecture pass for the moment between beat sheet and script. Its job is to keep Page 1 and the rest of Issue #1 from becoming only a cool image sequence. The present-day wrong-route incident remains the readable survival story, while the older W.A.S. disaster bleeds through equipment, route memory, corrupted signal, and visual echoes.

Use this pass before scripting, thumbnailing, or generating finished page art.

---

## Hybrid Structure Rule

```text
The present-day crew lives the incident.
The W.A.S. crew haunts the evidence.
```

Issue #1 should still function as a present-day Traverse survival horror incident. The W.A.S. layer should not hijack the A-plot. It should appear as interference, reflection, old telemetry, wrong route logic, corrupted file fragments, obsolete equipment behavior, and emotional residue.

The reader should feel the old disaster before they understand it.

---

## Reveal Discipline

Use these rules across the issue:

```text
No full W.A.S. explanation before Page 22.
No readable W.A.S. personnel names before Page 22.
No C.A.S.E. reveal in Issue #1.
No full flashback sequence unless a later script pass deliberately assigns one.
No stopping the present-day survival problem to explain the old disaster.
```

Allowed before Page 22:

```text
partial route labels
legacy file fragments
old telemetry stutter
misaligned timestamps
cab reflections that feel older than the cab
radio ghosts under static
route data that briefly behaves like archival data
objects whose emotional meaning is not yet explained
```

The Page 22 file reveal should remain the first clean confirmation that the wrong-route incident connects to the W.A.S. Traverse.

---

## C.A.S.E. Exclusion Rule

C.A.S.E. is the later institutional horror layer, not the Issue #1 reveal.

Issue #1 reveals W.A.S. first:

```text
W.A.S. TRAVERSE
CORE TRANSIT INCIDENT
PERSONNEL STATUS: UNRESOLVED
```

C.A.S.E. should remain buried for a later file reveal, when the story is ready to show that the institution returned after W.A.S. to contain, redact, stabilize, and misname the disaster.

# Page 1 Production Implication

Page 1 should now be built as a present-day opener with one controlled W.A.S. contamination.

Required elements:

```text
inside lead tractor cab
fogged windshield
black-blue mineral mist
headlights on wet frozen flats
clean physical flags
rookie watching flags more than monitor
dashboard glow
wiper streaks
condensation
route monitor disagreement
one subtle older-cab or legacy-route reflection
```

Forbidden on Page 1:

```text
full W.A.S. file
Rookmask Jack reveal
Jasper reveal
C.A.S.E. reference
readable Mark Aggressive ID
full flashback panel
crew wandering outside
city vista replacing the route problem
```

The page should whisper:

```text
The road is already lying, but the machine has not admitted it yet.
```
