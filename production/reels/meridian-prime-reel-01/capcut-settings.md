# CapCut Global Settings

## Global grade

Use **Adjust -> Apply all**.

| Control | Value |
|---|---:|
| Brightness | -6 |
| Contrast | +12 |
| Saturation | -15 |
| Highlights | -18 |
| Shadows | -5 |
| Temperature | -3 |
| Sharpness | 0 |

Optional finishing texture:

- Grain: 3-6
- Vignette: 5-8

## Avoid

- heavy global filters
- sharpening
- bloom
- glitch effects
- HDR look
- decorative transitions
- film-damage overlay
- logo/outro card on Reel 01

## Cut behavior

Hard cuts only. The opening should begin immediately on picture. The ending should cut hard to black.

## Export guidance

- 1080 x 1920
- use source frame rate
- high bitrate
- H.264
- no watermark

These settings are the retained glue layer. Individual shots may still need tiny shot-level exposure corrections if a source generation falls outside the shared visual physics.
